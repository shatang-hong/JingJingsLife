# 24 · 版本路线

> 上游：[12-PoC范围](12-PoC范围.md)｜ [23-渠道适配](23-渠道适配.md)
> 性质：架构阶段的分期，只定「每一版解决什么问题」，不定日期。

## 一、先区分两件事

| | 回答什么 | 在哪 |
|---|---|---|
| **PoC（阶段 A–D）** | 这套假设**成不成立** | 12 |
| **版本（V1–V3）** | 这套东西**能不能用、能用到什么程度** | 本文 |

PoC 是验证，版本是交付。**PoC 通过才谈版本。**

---

## 二、四期

| 期 | 目标 | 一句话判据 |
|---|---|---|
| **PoC** | 证明机制成立 | 隔三天再聊，它能自然接上 |
| **V1** | 一个人日常可用 | 连续跑两周不崩、不断片 |
| **V2** | 长期运行不腐化 | 跑满三个月，记忆不失控、成本可见 |
| **V3** | 多角色共存 | 两个角色互不干扰 |

---

## 三、各期范围

### 3.1 PoC

见 12 的四阶段。范围：单角色、单 QQ 账号、至少一个群、L0+L1 整理。

**不含**：L2/L3、周记月报、知识库、归档、向量、多角色、微信。

### 3.2 V1 · 单人日常可用

| 加入 | 为什么必须 |
|---|---|
| **L2 深整理** | 没有它，记忆只增不减，一个月后就臃肿 |
| **周记** | 深整理的自然产物，也是「它在生长」的唯一可见证据 |
| **归档** | PoC 只跑两周看不出问题，跑一个月必须归档 |
| **最小 GUI** | 认领、配置、关系浏览要能用鼠标完成 |
| **安全拦截完整版** | L1 基线 + L3 兜底（PoC 只有 L2） |

**仍不含**：L3 月度、知识库、向量、多角色、微信。

### 3.3 V2 · 长期运行

| 加入 | 为什么 |
|---|---|
| **L3 月度整理** | 趋势、真正的遗忘、维度演进提议——都需要月级视野 |
| **月报** | 与周记同源 |
| **知识库** | 记忆膨胀后再靠 grep 会失效，需要按主题沉淀 |
| **成本预算**（可选开启） | 跑三个月后才知道钱花在哪 |
| **数据体检** | 索引与真源对账 |

### 3.4 V3 · 多角色

| 加入 | 说明 |
|---|---|
| 多内核实例 | 一个角色一个进程（22 的第二节） |
| 角色清单与切换 | GUI 多面板 |
| 跨角色隔离校验 | 确保没有共享状态 |

**微信仍在 V3 之后决定**。它需要的不是版本，是「值不值得维护一个随客户端版本失效的适配器」。

---

## 四、每期都要守的东西

版本可以砍功能，但**不能砍不变式**。

| 期 | 必须已经成立 |
|---|---|
| PoC | I1（数据在内核）、I2（单注意力） |
| V1 | I3（内核不推理）、I4 的前两层（值可变、结构暂固定） |
| V2 | I4 全量（维度可演化） |
| V3 | 全部 |

这条的意义：**功能可以延后，地基不能延后。** 一个 V1 就违背 I1 的实现，到 V3 也修不回来。

---

## 五、数据格式的向前兼容

跨版本迁移只靠一个字段：`identity/manifest.json` 的 `format_version`（06 的 4.5）。

规则：

| 情况 | 处理 |
|---|---|
| 新版读旧版数据 | 允许，自动迁移并升 `format_version` |
| 旧版读新版数据 | **拒绝启动**，不尝试降级 |
| 迁移失败 | 保留原数据，报错退出（不做部分迁移） |

> **宁可不启动，不可读一半。**

---

## 六、一个反向原则：什么情况下不升级

升级不是默认动作。以下情况应该**停在当前版本**：

| 情况 | 理由 |
|---|---|
| 现有版本没暴露问题 | 升级带来的风险大于收益 |
| 升级需要改数据格式且无回滚路径 | 冷静期只有 2 天，不够后悔 |
| 只是「想试试新功能」 | 角色不是玩具，它的连续性比功能重要 |

这与 19 的身份分层是同一个逻辑：**稳定性本身就是价值。**

## 七、未决

1. **V1 的「两周不崩」怎么判定**：用什么指标？（无 ERROR、记忆不丢、上下文不爆）
2. **L2 的引入时机**：PoC 跑完立刻上，还是再观察一段？
3. **知识库与记忆的边界在 V2 会模糊**：需要一次专项校准。
4. **多角色时 GUI 的形态**：单窗口多面板，还是多窗口？
5. **微信的决策点**：是「永远不做」还是「等官方接口稳定」？
