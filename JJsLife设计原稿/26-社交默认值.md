# 26 · 社交默认值（T1 / T2）

> 上游：[03-实时记忆](03-实时记忆.md)｜ [09-人格侧面投影](09-人格侧面投影.md)｜ [17-故障与降级](17-故障与降级.md)
> 本文解决 08 中长期挂起的 T1（可以不回复）与 T2（打断与接续）。

## 一、问题

设计允许输出 `SILENCE`，但它几乎总会回复：要解决的正是「**什么情况下沉默是合适的**」。

## 二、权重不是概率，是判据

**人是有理由不说话的**，权重是一组判据而非概率：

| 情形 | 该不该回 |
|---|---|
| 群里 A 跟 B 说话没点我；已有人回答充分；对方在抒情绪；我无话可说；场合不适合 | 可以不回 |
| 私聊、直接 @ 我、回复我的消息 | **必须回** |

## 三、T1 的三层结构

### 3.1 第一层：硬规则（内核执行，不给判断）

| 条件 | 处理 |
|---|---|
| 私聊（`is_group=false`） | 内核**必须投递**（管理员显式允许沉默除外） |
| 直接 @ 我（带 at 标记） | 内核**必须投递** |
| 回复我的消息（`reply_to` 指向自己） | 内核**必须投递** |
| 群里提名但没 @（「XX 你觉得呢」） | 交给 DSH 判断 |

前三条结构可判，符合 I3。**再内向的角色也不该让私聊的人独自等待。**

### 3.2 第二层：判据清单（DSH 用）

硬规则允许时，DSH 按第二节判据表判断，**沉默必须对得上其中一条**。

### 3.3 第三层：档位（人格定宽严）

话量是性格，写在 `persona.md` 的 `social_prior.silence_level`（四档，调门槛不调概率）：

| 档位 | 允许沉默的范围 |
|---|---|
| 有问必答 | 只在「对象不是我」时 |
| 谨慎 | + 已有人回应充分 |
| **自然**（默认） | + 对方抒情绪 + 我无话可说 |
| 多听少说 | + 只要不是 @ 我 |

## 四、T2：接续是被动的，不是主动的

**主动回去属于主动聊天**（[12](12-PoC范围.md) 第三节明确不做）。**不需要。**

**只需一条注入规则**——03 的体验块（位置、情绪基调、未完成、意图残留）已解决八成：

> **下次进入该节点时，若体验块的「未完成」非空，显式提示 DSH。**

提示形如「你上次和这个群说话是 12 分钟前，有件事没说完：A 问了问题你没答完」。提不提由 DSH 判断，**这本身也是社交判断**。

**放弃也是一种接续**：重要的下次自然提起，过期的只留在记忆里，被忘记的由新体验块覆盖（**体验块只有最新一条**，03 的 6.6）。

## 五、沉默怎么被记录

记忆层**正常走**（「看到了但没说话」也是经历）；便签按原规则；trace 记 `decision: SILENCE` + 命中判据（复盘「为什么没理我」的唯一依据）；审计无关。

## 六、与已有设计的关系

| 已有设计 | 关系 |
|---|---|
| 03 的 `scope`「说不说由 DSH 判断」 | 同一套倾向，T1 是它的另一半（对内沉默 / 对外转述） |
| 17 的「过期消息不回」 | **不是同一件事**：T1 不想回，17 回得不对，别混成一个开关 |
| 09 的行为集／21 的输出形式 | 档位属人格、不占 schema；沉默时输出参数不生效 |

## 七、反面清单

| 不做 | 理由 |
|---|---|
| 概率式沉默；沉默时回「嗯」 | 随机无视与敷衍，都比不回更伤人 |
| 让内核判断该不该沉默 | 需理解语义，违反 I3 |
| 沉默后补「刚才没看到」 | 撒谎且容易被戳穿 |
| 所有渠道用同一套门槛 | 私聊与群聊礼数不同 |

## 八、未决

1. **`silence_level` 是否按节点区分**：对某个群可以更沉默吗？倾向可以（写进 `overrides`）。
2. **长期沉默的代价**：一个群连续一个月没说话，要不要提示管理员？
3. **沉默的上限**：私聊若配置为「允许沉默」，多久算失联？
4. **判据如何演进**：清单是手写的，能否从「用户不满」里学习？（属 L2 维度演进范畴，暂不做）
5. **被沉默者的感受**：技术上无法知道对方是否因没被回复而不适——除非对方说出来。
